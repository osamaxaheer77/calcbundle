What Base64 actually is

Base64 isn't encryption — it's a way to represent arbitrary binary data (or text) using only 64 printable ASCII characters (A–Z, a–z, 0–9, +, /), so it can be safely embedded in places that expect plain text, like JSON, URLs, or email. Anyone can decode it back instantly; it provides no confidentiality.

Where it shows up

Common uses include embedding small images directly in CSS or HTML (data URIs), encoding email attachments, and representing binary tokens or credentials in text-based protocols and config files.

Both conversions happen locally in your browser using the standard btoa/atob functions — nothing you type here is sent anywhere.

Common questions

Why does encoded text look longer than the original?

Base64 represents every 3 bytes of input as 4 output characters, so encoded text is roughly 33% longer than the original.

Can I use this to encode special characters and emoji?

Yes — text is converted to UTF-8 bytes before encoding, so non-English text and emoji round-trip correctly.
