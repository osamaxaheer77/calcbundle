Password Generator

Generate a secure, random password with customizable length and character types, entirely in your browser.

By Osama · Last reviewed November 6, 2026

Quick answer. A strong password is long and random. A 16-character password using all four character types (94 possible characters) has 104.9 bits of entropy, which this page rates Strong, and each extra character adds about 6.6 bits. Passwords are generated in your browser and never sent anywhere.

Generated entirely in your browser

The password is built in your browser with crypto.getRandomValues, the cryptographically secure random number generator that browsers provide. It is never sent to a server and is not stored, so only you ever see it. Copy it into a password manager before you leave the page, because it cannot be recovered.

How the generator works

  • You choose a length from 1 to 128 and which sets to include: lower case (26), upper case (26), numbers (10) and symbols (32).
  • Optional filters remove ambiguous characters (such as i, I, l, 1, L, o, 0, O and some punctuation) or brackets, and an option stops any character repeating.
  • Each character is picked independently and uniformly from the remaining set, using a method that avoids the slight bias of a plain remainder.
  • With the no-repeat option the length cannot exceed the number of available characters, and the page tells you so.

What entropy means

Entropy measures how unpredictable a password is, in bits. Each extra bit doubles the number of guesses an attacker needs on average. For a random password it is length × log2(character set size). The default is 16 characters from all four types (94 possible characters): 16 × log2(94) = 104.9 bits, which the page rates Strong. Each extra character adds about 6.6 bits, so going from 16 to 20 characters makes the password roughly 78,100,000 times harder to guess.

Removing ambiguous characters or brackets shrinks the set, so you lose a little entropy per character. Make up for it with extra length. Because each character is chosen at random, a password is not guaranteed to contain every selected type: with all four types and 16 characters, about 17% of passwords contain no digit and about 0.1% contain no symbol. If a site insists on one of each, generate again or add a character.

Good practice

  • Use at least 14 to 16 characters, and a unique password for every account.
  • Keep passwords in a reputable password manager rather than a note or spreadsheet.
  • Turn on two-factor authentication for important accounts.
  • Current NIST guidance favours length and checking against known breached passwords over forced complexity rules or regular changes.

A passphrase of several random words is another good option for passwords you must remember, as long as the words are chosen at random and not from a song or quote. Use the generator for everything else, and let a password manager remember it.

Common mistakes

  • Reusing one strong password on several sites.
  • Making a short password with substitutions such as P@ssw0rd, which attackers guess first.
  • Using personal facts, names or dates.
  • Forgetting to save the generated password before leaving the page.

How to read your result

The large box shows the password. Below it you see the entropy in bits and the strength rating. Treat anything under 60 bits as weak for important accounts. For a Wi-Fi or shared login that you must type by hand, turn on the ambiguous-character filter and use a longer length.

Never share a password you generated here or reuse it. This tool does not check whether a password has appeared in a data breach.

Common questions

Why exclude ambiguous characters?

Characters like l, 1, I, O and 0 are hard to tell apart in some fonts. Excluding them helps when you must type the password by hand from a printout.

Is it safe to generate my password on this page?

Yes. Generation happens locally in your browser using the secure random number generator. Nothing is transmitted or stored.

How long should my password be?

At least 14 to 16 random characters for important accounts. Length adds strength faster than symbols do.

What does entropy in bits mean?

It is a measure of unpredictability. Each extra bit doubles the number of guesses needed. A random password has length times log2 of the character set size in bits.

Will every password contain a symbol and a number?

Not always. Characters are chosen at random from the selected sets, so a password can miss a type. Generate again or lengthen it if a site requires one of each.

Should I change my passwords regularly?

Current NIST guidance says to change a password when there is evidence it is compromised, not on a fixed schedule, and to use a unique password for every account.
