Password Generator

Generate a secure, random password with customizable length and character types, entirely in your browser.

Generated entirely in your browser

This password is created using your browser's cryptographically secure random number generator (crypto.getRandomValues) and never leaves your device or gets sent anywhere — there's no server involved.

What "entropy" means

Entropy measures how unpredictable a password is, in bits. Each additional bit doubles the number of guesses an attacker would need to try, on average, to find your password by brute force. Longer passwords and larger character sets (more symbol types) both increase entropy.

A unique, sufficiently long password for every account (ideally paired with a password manager) is far more effective than a single "clever" password reused everywhere.

Common questions

Why exclude ambiguous characters?

Characters like "l", "1", "I", and "O", "0" can be hard to tell apart in some fonts — useful to exclude if you'll need to type the password by hand from a printout.

Is it safe to generate my password on this page?

Yes — the generation happens locally in your browser using JavaScript. Nothing is transmitted or stored.
