Random Number Generator

Generate one or many random integers or decimals within a range, with or without repeats.

How random is this?

This generator uses your browser's built-in pseudo-random number generator, which produces numbers that are statistically indistinguishable from true randomness for everyday purposes — picking a raffle winner, rolling for a game, shuffling a list. It's not suitable for cryptography or security-sensitive uses, which require specialized random sources.

Integers vs. decimals

Integer mode returns whole numbers only, evenly spread across your range. Decimal mode returns numbers with a fractional part, rounded to however many digits of precision you choose — useful for things like simulating measurements or generating test data.

With duplicates disallowed, the number of unique integers you can request is capped by the size of your range — you can't generate 50 unique numbers from a range of only 20 possible values.

A worked example

Set the lower limit to 1 and the upper limit to 100, and the generator returns a whole number from 1 to 100, with each number equally likely. Ask for 10 numbers with repeats turned off and you get 10 different values, like drawing numbers from a hat. Turn on decimal precision to get numbers such as 42.37.

Tips for fair draws

For a raffle or a classroom pick, give each person a number and generate within that range. Use the no-repeat option when the same number must not come up twice. Each click is independent, so seeing the same number twice in a row is normal. The generator is not suitable for cryptography or for gambling, where regulated sources apply.

Common questions

Why would I disallow duplicates?

Useful whenever each result needs to be unique — assigning raffle numbers, shuffling a deck, or picking several different winners from a pool without repeats.

Does refreshing give a different result?

Yes — every time you click Generate, a fresh set of random numbers is produced. Nothing is cached or remembered between runs.
