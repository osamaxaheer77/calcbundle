Percent Error Calculator

Compare a measured value with the true value to see how far off it is as a percentage, with the working shown.

By Osama · Last reviewed November 6, 2026

Quick answer. Percent error = (observed − true) ÷ |true| × 100. An observed 10 against a true 11 is -9.0909%, or 9.0909% absolute. A reading of 56.891 against 62.327 is -8.7217%.

What percent error is

Percent error shows how far a measured, or observed, value is from the true (accepted) value, as a percentage of the true value. It is used in science classes and labs to judge how good a measurement is. A small percent error means the measurement is close to the accepted value, and a large one suggests a mistake in the method or the equipment.

The formula

Percent error = (observed − true) ÷ |true| × 100. Subtract the true value from the observed value, divide by the size of the true value, and multiply by 100. The result is negative when the observed value is lower than the true value and positive when it is higher. Many textbooks use the absolute value so that the error is always positive, since only its size matters. The calculator shows both the signed error and the absolute error, as well as the plain difference.

Worked example with the default numbers

The page opens on an observed value of 10 and a true value of 11. The difference is 10 − 11 = −1. Divide by 11 to get −0.0909, and multiply by 100: a percent error of -9.0909%, which is an absolute error of 9.0909%. The tool lists each step: (10 − 11) ÷ 11 × 100 = −1 ÷ 11 × 100 = −0.09090909 × 100 = -9.0909%. The absolute error in the units of the measurement is 1.

Over and under

Readings above and below the true value give errors of opposite sign. With a true value of 50, a reading of 55 has a percent error of +10% and a reading of 45 has −10%. The sign tells you the direction, which can help you find the cause: a thermometer that always reads low, for example, gives a negative error every time.

What counts as a small error?

There is no universal limit. A school lab might accept an error under 5% and a precision experiment might need 0.1% or better. Compare your result with what the method and the equipment can deliver. If the percent error is larger than the stated precision of your instrument, look for a systematic problem such as a miscalibrated scale, a heat loss, or a reading taken from the wrong angle.

Special cases

  • A true value of zero. Percent error is undefined, because the formula divides by the true value. Use the absolute error instead.
  • A negative true value. The calculator divides by the size of the true value, so a reading above the true value always has a positive error. For true −10 and observed −9, the error is +10%.
  • When the true value is unknown. Scientists use the spread of repeated measurements, such as the standard deviation, to describe uncertainty instead.

Percent error and other percent measures

Percent error compares a measurement with a known standard. Percent change compares an old and a new value. Percent difference compares two values when neither is the standard. The formulas look alike but use different bases, so pick the one that fits. The Percentage Calculator covers percent change and difference.

Common mistakes

  • Dividing by the observed value instead of the true value.
  • Forgetting to multiply by 100.
  • Swapping the observed and true values, which changes the sign and, slightly, the size of the result.
  • Reporting a negative error when your textbook asks for the absolute value.
  • Rounding too early. Keep extra decimals until the last step.

Common questions

How do you calculate percent error?

Subtract the true value from the observed value, divide by the true value, and multiply by 100. An observed 10 against a true 11 gives minus 9.0909 percent.

Can percent error be negative?

Yes. It is negative when the observed value is lower than the true value. Many textbooks use the absolute value so the error is always positive, and the calculator shows both.

What if the true value is zero?

Percent error is undefined, because it would mean dividing by zero. Use the absolute error in the units of the measurement instead.

What is a good percent error?

It depends on the experiment. A school lab might accept under 5 percent, while a precision measurement may need under 0.1 percent. Compare it with what your equipment can deliver.

What is the difference between percent error and percent change?

Percent error compares a measurement with a known true value. Percent change compares a new value with an old one. Both use a similar formula but with different bases.

What if I do not know the true value?

Percent error needs one. When it is unknown, scientists use the standard deviation of repeated measurements to describe the uncertainty instead.
