How hexadecimal works

Hexadecimal, or hex, counts in base 16. It needs sixteen digits, so after 0 to 9 it uses the letters A to F for the values 10 to 15. Each place is worth sixteen times the one to its right. The hex number 2F is 2 × 16 + 15, which is 47 in decimal. Hex is popular in computing because one hex digit stands for exactly four binary digits, so long binary numbers become short and easy to read.

Worked example with the default numbers

The page opens with 8AB and B78, which are 2,219 and 2,936 in decimal. Adding them gives 1423 in hex (2,219 + 2,936 = 5,155). Column by column: B + 8 = 19, which is 13 hex, so write 3 and carry 1; and so on until the sum is 1423. Subtracting gives -2CD (-717), multiplying gives 636928 (6,514,984) and dividing 8AB by B78 gives a quotient of 0 and a remainder of 8AB (in decimal 0 remainder 2219).

Converting hex to decimal

Multiply each digit by 16 raised to its position, counting from 0 at the right, and add the results. DAD is 13 × 256 + 10 × 16 + 13 = 3,501, the page’s default hex-to-decimal example. The number 8AB is 8 × 256 + 10 × 16 + 11 = 2,219.

Converting decimal to hex

Divide the number by 16 repeatedly, keep the remainders and write 10 to 15 as A to F. Reading them from the last to the first gives the hex number. For 3,501:

Reading the digits bottom to top gives DAD. The page’s decimal-to-hex default is 170, which is AA (10 × 16 + 10).

Hex and binary

One hex digit equals exactly four binary digits (bits), so a byte of 8 bits is two hex digits, with values from 00 to FF, or 0 to 255 in decimal. To convert, replace each hex digit with its four bits: A is 1010, so AA is 10101010, which is 170 in decimal. The Binary Calculator does arithmetic in base 2.

Where hex is used

  • Web colors: #FF8800 sets red to FF (255), green to 88 (136) and blue to 00 (0), which is orange.
  • Memory addresses and MAC addresses: long values are written in hex.
  • Character codes and byte values: programmers read hex when they debug.
  • Unicode: code points are written in hex, such as U+00E9.

Entering numbers

  • Use digits 0 to 9 and letters A to F, upper or lower case. Results are shown in upper case.
  • A 0x prefix, such as 0x8AB, is accepted and ignored.
  • Negative whole numbers use a minus sign.
  • Only whole numbers are supported. Fractions and two's complement are not used.
  • The sums are exact for numbers of any size.

Common mistakes

  • Using letters beyond F, such as G.
  • Forgetting that D is 13, not 4, when converting by hand.
  • Confusing the decimal number 170 with the hex number 170, which is 368 in decimal.
  • Dividing and expecting a fraction. Division gives a whole quotient and a remainder.

Common questions

How do you add hex numbers?

Add the digits column by column from the right, using decimal values for the letters. When a column reaches 16 or more, write the remainder and carry 1. For example, 8AB + B78 is 1423.

What do the letters A to F mean in hex?

They stand for the values 10 to 15: A is 10, B is 11, C is 12, D is 13, E is 14, and F is 15.

How do I convert hex to decimal?

Multiply each digit by 16 raised to its position, counting from 0 at the right, and add them up. DAD is 13 x 256 + 10 x 16 + 13, which is 3,501.

How do I convert decimal to hex?

Divide the number by 16 repeatedly and keep the remainders, writing 10 to 15 as A to F. Reading the remainders from last to first gives the hex number.

Why is hex used with binary?

One hex digit equals exactly four binary digits, so a byte is two hex digits. It is a compact way to write binary values.

Does the calculator accept a 0x prefix?

Yes. A leading 0x is ignored, so 0x8AB and 8AB give the same result.
