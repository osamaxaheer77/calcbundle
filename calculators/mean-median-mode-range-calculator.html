Mean, Median, Mode, Range Calculator

Calculate the mean, median, mode, and range of a data set — four different ways of summarizing the same numbers.

Four different ways to summarize data

Mean is the arithmetic average — sum divided by count. Median is the middle value once the data is sorted (or the average of the two middle values, for an even count). Mode is whichever value appears most often — a data set can have no mode, one mode, or several (multimodal) if there's a tie. Range is simply the largest value minus the smallest.

Why the median resists outliers

Mean and range are both easily distorted by a single extreme value, since they depend on the actual magnitude of every number. Median doesn't — it only cares about position in the sorted order, so an outlier just becomes the new highest (or lowest) value without shifting the middle. That's why median is often a better "typical value" for skewed data, like income or home prices.

Always look at more than one of these together. A data set can have the same mean as another and still look completely different in spread and shape — mean, median, mode, and range each reveal something the others miss.

A worked example

Take the numbers 10, 2, 38, 23, 38, 23 and 21. Sorted, they read 2, 10, 21, 23, 23, 38, 38. The sum is 155 and there are 7 values, so the mean is 22.1429. The median, the middle value, is 23. The mode is both 23 and 38, since each appears twice. The range is 38 − 2 = 36.

Tips for summarizing data

Use the median when the data has outliers, because one very large value pulls the mean up but barely moves the median. The mode is the only one of the four that works for categories as well as numbers. If a set has no repeated value there is no mode, and a set can have more than one. Separate the numbers with commas or spaces, and check for typos, since one wrong digit can change the mean.

Common questions

What if every value appears exactly once?

Then there's no mode — nothing repeats, so nothing qualifies as "most frequent."

Can there be more than one mode?

Yes — if two or more values tie for the highest frequency, the data set is multimodal and all of them are reported as modes.
