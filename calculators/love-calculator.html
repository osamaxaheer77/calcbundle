Love Calculator

A just-for-fun compatibility score based on two names. For entertainment only!

By Osama · Last reviewed November 6, 2026

Quick answer. A novelty percentage from two names, with no science behind it. Alex and Jordan score 80%. The same pair always gets the same score, and the order of the names does not matter.

Just for fun

This calculator turns two names into a percentage. It is a novelty: the score comes from a simple formula, not from astrology, numerology or any real measure of compatibility. Treat it the way you would a fortune cookie, and use it as a party game or a conversation starter.

Worked example with the default names

The page opens on Alex and Jordan. The score is 80%, with the message “A strong match — the chemistry is there.” The calculator lowercases both names, trims the spaces at the ends, puts them in alphabetical order and joins them with a bar, giving “alex|jordan”.

How the score is made

  • Each name is lowercased and trimmed, so “ALEX” and “ alex ” are the same.
  • The two names are sorted alphabetically and joined as first|second. Sorting is why the order you type them in makes no difference.
  • The letters are run through a simple hashing formula: start at 0, and for each character multiply the running total by 31 and add the character’s code, keeping only the last 32 bits.
  • The final number is divided by 101 and the remainder, from 0 to 100, is the score.

For “alex|jordan” the running total ends at 82,326,594, and 82,326,594 mod 101 = 80.

Why trying again does not help

The same pair of names always gives the same score, and swapping the order changes nothing, so there is no point in retyping for a better number. Changing a single letter does change the score, because every character feeds the formula: Alex and Jordan give 80%, Alexa and Jordan give 67%, and Alex and Jordann give 65%. That shows how arbitrary the result is.

Please keep it light

The score says nothing real about any relationship. Real compatibility comes from shared values, communication, respect and time spent together. Share the page with friends, but do not base any decision on the number. A conversation with the actual person is worth more than any formula.

Common questions about the score

  • Does it use birthdays or zodiac signs? No, only the two names you type.
  • Does a nickname change the result? Yes. Any change in the letters changes the score.
  • Does it work with any language? It works with any letters, though the value depends on the character codes.
  • Is my data stored? The page works in your browser with the names you type, and it does not need an account.

Common questions

Is the love calculator accurate?

No. It is for entertainment only. The score comes from a simple formula applied to the letters of the two names, with no science behind it.

Why does the same pair of names always give the same score?

The formula has no randomness. It combines the two names the same way every time, so identical input gives an identical result.

Does the order of the names matter?

No. The two names are sorted alphabetically before the formula is applied, so swapping them gives the same score.

Does capitalisation matter?

No. Names are converted to lowercase and trimmed before the score is worked out.

Why does one extra letter change the score?

Every character is part of the formula, so any change to a name produces a different number.

What does a high score mean?

Nothing about a real relationship. Real compatibility comes from shared values, communication, respect and time spent together.
