Love Calculator

A just-for-fun compatibility score based on two names. For entertainment only!

Just for fun

This calculator turns the two names you enter into a percentage using a deterministic formula — the same pair of names always gives the same score, and swapping the order doesn't change the result. It isn't based on any real measure of compatibility; treat it the same way you would a fortune cookie.

How the score is generated

Both names are combined and run through a simple hashing function that turns text into a number between 0 and 100. There's no astrology, numerology, or actual relationship science involved — it's purely a novelty calculation.

For real relationship insight, a conversation with the actual person will always beat a random number generator.

Common questions

Does the order I enter the names matter?

No — "Alex & Jordan" and "Jordan & Alex" always produce the same score.

Can I get a different score for the same two names?

No — the result is deterministic, so re-calculating with identical names (and capitalization/spacing ignored) always gives the same percentage.
