Privacy Policy

Short version: our calculators run entirely in your browser. We don't have a server collecting what you type into them, because we don't have a server at all.

What we don't collect

CalcBundle is a static site — every calculator is plain HTML, CSS, and JavaScript that runs entirely on your own device. The numbers you type into a calculator, the results it produces, and any inputs you adjust never leave your browser. We have no database, no account system, and no server-side code that could receive or store that information even if we wanted to.

Server & hosting logs

Like any website, the infrastructure that serves these pages to your browser keeps basic technical logs as a normal part of operating on the internet — things like your IP address, browser type, and which pages were requested. This is standard web hosting behavior handled by our hosting provider, not something CalcBundle itself collects, stores, or has access to for analysis.

Cookies & tracking

CalcBundle does not set any cookies and does not run any analytics or advertising scripts at this time. If that ever changes — for example, if we add privacy-respecting analytics down the road — we'll update this page to describe exactly what's added and why.

If you ever notice this page doesn't match what the site actually does, that's a bug — please let us know via the Contact page.

Links to other sites

Some pages may link out to external resources or references. We aren't responsible for the content or privacy practices of any site we don't operate, and we'd encourage you to review the privacy policy of any third-party site you visit from here.

Children's privacy

CalcBundle isn't directed at children and doesn't knowingly collect any information from anyone, of any age — see above.

Changes to this policy

If our practices change — for instance, if we introduce accounts, saved calculations, or analytics — we'll update this page and adjust the description above to stay accurate.

Questions

Reach out any time via the Contact page.
